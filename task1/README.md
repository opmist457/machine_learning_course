Boolean Functions using MP Neuron Model

This task implements basic Boolean functions (AND and OR) using the McCulloch–Pitts (MP) neuron model.

The MP neuron computes the sum of binary inputs and applies a threshold to generate a binary output:

AND: Output is 1 only if all inputs are 1 (threshold = number of inputs).

OR: Output is 1 if at least one input is 1 (threshold = 1).

The implementation includes input validation to ensure only binary values (0 or 1) are accepted.

Language Used: Python
Concepts Covered: MP neuron, threshold logic, Boolean functions

HOW TO RUN : Just run "main.py" file
